# My Personal Portfolio Website

## About the Project

This is my personal portfolio website, developed as part of my COS 106 coursework at MIVA Open University.

The website introduces me, showcases my skills and projects, and includes an academic planner to help me organise my school tasks.

## Features

- **Home:** Personal introduction and welcome section.
- **About:** Educational background, skills and interests.
- **Projects:** Displays some of my completed projects.
- **Academic Planner:** Allows me to add academic tasks.
- **Contact:** A form for visitors to send messages.
- **Introduction Audio:** An audio introduction on the home page.

## Technologies Used

- HTML5
- CSS3
- JavaScript
